# SimpleMail

Простой почтовый клиент на Python + Qt (PySide6). Письма хранятся локально в SQLite.

## Что умеет

- Несколько почтовых ящиков (IMAP для приёма, SMTP для отправки). Для Gmail, Яндекса, Mail.ru, Rambler, Outlook серверы подставляются сами по адресу.
- Порядок ящиков меняется перетаскиванием в главном дереве или в окне «Почтовые ящики», а также кнопками «Вверх»/«Вниз» (`Ctrl+↑` / `Ctrl+↓`) в этом окне; порядок сохраняется после перезапуска.
- Входящие, Спам, Отправленные, Корзина, локальные Черновики и Исходящие; остальные серверные папки появляются в дереве после проверки.
- Спам-фильтр:
  1. белый список (отправитель / тема / текст) — никогда не спам;
  2. чёрный список — всегда спам;
  3. если сервер поставил `X-Spam-Flag: YES` — спам;
  4. байесовский фильтр, который учится на кнопках «Спам» / «Не спам» (включается после 5 писем каждого вида).
  Почему письмо попало в спам — видно в подсказке к строке и в заголовке письма.
- Редактор письма с оформлением (шрифты, цвета, списки, таблицы, картинки, ссылки) или обычный текст; несколько подписей (Настройки → Подписи), у каждого ящика своя подпись по умолчанию, в окне письма её можно сменить.
- Ответить, ответить всем, переслать, перенаправить, быстрый ответ; вложения.
- Раскладки окна (Вид → Раскладка окна): классическая, «письмо справа», только список. Колонки списка настраиваются (правый клик по заголовку), сортировка кликом; вид окна запоминается.
- Фоновый поиск по отправителю, получателю, теме, тексту письма и именам вложений: в папке, ящике или во всех ящиках, с фильтром дат и непрочитанных. `Ctrl+Shift+F` — поиск по всем ящикам. Результаты загружаются порциями по 500, кнопка «Показать ещё» открывает следующую порцию.
- Синхронизация серверных папок и прочтения, IMAP IDLE для входящих, резервная проверка по таймеру, F5 — проверить сейчас.
- Автосохранение черновиков и быстрых ответов, постоянная очередь исходящих, полная загрузка истории с паузой и продолжением, резервное копирование и восстановление.
- HTML-письма показываются встроенным браузером без зависаний; картинки из интернета загружаются только по кнопке «Показать картинки» (защита от слежки), JavaScript выключен.
- Светлая и тёмная темы автоматически следуют настройке системы и переключаются без перезапуска, включая просмотр писем, значки и окна настроек.

## Установка (Windows)

1. Установите Python 3.11+ с python.org (галочка «Add python.exe to PATH»).
2. В папке программы:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   python main.py
   ```
3. При первом запуске откроется окно «Почтовые ящики» — добавьте ящик.

> Для Gmail, Яндекса и Mail.ru нужен **пароль приложения** (создаётся в настройках безопасности аккаунта), обычный пароль не подойдёт. В Яндексе также включите доступ по IMAP в настройках почты.

Пароли хранятся в системном хранилище Windows (Диспетчер учётных данных) через `keyring`. Если оно недоступно, пароль сохраняется в базе открытым текстом.

## Где хранится почта

- **Копии писем и вручную сохранённые вложения** — в папке хранения ящика (задаётся в настройках ящика, по умолчанию `Документы\SimpleMail\<адрес>`):
  - `Входящие\ГГГГ-ММ\*.eml`, `Отправленные\ГГГГ-ММ\*.eml` — письма целиком (с вложениями), открываются любым почтовым клиентом;
  - `Вложения\` — папка, которая предлагается по умолчанию при ручном сохранении вложений.
  При смене папки программа предложит перенести уже скачанные письма.
- **Список писем, вложения, настройки, правила спама** — `%APPDATA%\SimpleMail\mail.db`. Вложения автоматически сохраняются в SQLite при загрузке письма, с исходными именами и порядком. Другая папка: `python main.py --data D:\Mail`.

Новые вложения сохраняются в базу при загрузке письма. Старые письма читаются из локальных `.eml` без автоматического переноса данных. Читать скачанные письма, открывать и сохранять их вложения можно без интернета; сохранённые в базе вложения доступны даже при недоступности исходного `.eml`. Встроенные в письмо картинки остаются в `.eml`; внешние картинки и ссылки требуют интернета. При первой обычной проверке скачиваются последние 300 писем каждой папки; полную историю можно загрузить отдельно.

## История и синхронизация

«Файл → Скачать всю историю» загружает все доступные письма всех серверных папок включённых ящиков. Состояние загрузки показывается в строке статуса. «Приостановить загрузку истории» останавливает её после текущего сетевого запроса; уже скачанное сохраняется. Повторный запуск команды продолжает с недостающих писем. После обрыва соединения незавершённая загрузка продолжается при следующей проверке почты.

Прочтение с телефона обновляется при проверке; изменения прочтения, сделанные без сети в SimpleMail, отправляются на сервер при подключении. Перемещение другим клиентом отражается в серверных папках. Если письмо удалено с сервера или изменилось поколение UID, прежняя локальная копия сохраняется в «Локальном архиве». IDLE ускоряет обновление входящих; остальные папки проверяются по таймеру и F5.

## Черновики и исходящие

Текст, адресаты, оформление, встроенные картинки и вложения сохраняются в SQLite после изменения с задержкой около секунды и при закрытии окна. Быстрый ответ также сохраняется при смене письма. Открыть черновик или исходящее для редактирования можно двойным щелчком либо `Ctrl+O`. «Удалить черновик» явно удаляет сохранённый вариант.

«Отправить» сначала сохраняет письмо в постоянной очереди. При отсутствии соединения оно остаётся в «Исходящих» и повторяется при проверке включённого ящика. Если результат SMTP неизвестен или часть адресатов отклонена, автоматического повтора нет: состояние видно в списке, перед ручной повторной отправкой требуется подтверждение. Для одной базы допускается один процесс SimpleMail.

После успешного SMTP письмо сохраняется в серверной папке Sent. Если сохранение копии не удалось, повторяется только этот шаг, без повторной SMTP-отправки. Существующая серверная копия проверяется по Message-ID и содержимому. Старые локальные отправленные письма автоматически на сервер не загружаются.

## Резервная копия и восстановление

«Файл → Создать резервную копию…» создаёт архив `.smbak` с согласованным снимком SQLite и файлами папок ящиков, включая вручную сохранённые вложения. Копию можно делать из открытой программы.

«Файл → Восстановить резервную копию…» проверяет архив, распаковывает его в отдельную папку и создаёт страховочную копию текущих данных `before-restore-*.smbak` рядом с рабочей базой. После перезапуска устанавливается подготовленная база; исходные папки до восстановления сохраняются. Восстановленные исходящие требуют проверки доставки перед повторной отправкой, чтобы старый архив не вызвал повторную рассылку. Пароли из системного хранилища Windows в архив не экспортируются; при переносе на другой компьютер их потребуется указать заново.

## Устройство кода

| Файл | Что делает |
|---|---|
| `main.py` | запуск |
| `mailclient/db.py` | база SQLite: ящики, письма, правила, настройки |
| `mailclient/protocols.py` | IMAP-синхронизация, SMTP-отправка |
| `mailclient/sync.py` | серверные папки, флаги и загрузка полной истории |
| `mailclient/delivery.py` | постоянная очередь SMTP и серверная копия Sent |
| `mailclient/backup.py` | резервное копирование и проверяемое восстановление |
| `mailclient/mailparse.py` | разбор писем, кодировки, вложения |
| `mailclient/spam.py` | правила и байесовский фильтр |
| `mailclient/passwords.py` | хранение паролей |
| `mailclient/storage.py` | файлы писем .eml в папке ящика |
| `mailclient/errors.py` | понятные тексты ошибок подключения |
| `mailclient/ui/messages.py` | окна ошибок с кнопкой «Подробнее» |
| `mailclient/ui/main_window.py` | главное окно |
| `mailclient/ui/account_dialog.py` | настройка ящиков (сюда добавлять пресеты серверов) |
| `mailclient/ui/compose_dialog.py` | написание письма |
| `mailclient/ui/spam_dialog.py` | правила спама и порог |

Тесты (без сети): `python -m unittest discover tests`

## Ограничения текущей версии

- При первой обычной проверке загружаются последние 300 писем каждой папки (настройка `initial_fetch_limit`); остальное доступно через загрузку полной истории.
- Кнопки «Спам» / «Не спам» перемещают письмо в обнаруженную серверную папку Junk и обратно. Если такой папки нет, спам отделяется локально.
- Удаление перемещает письмо в серверную корзину; локальная копия и вложения сохраняются. `Ctrl+Z` отменяет последнее удаление. В корзине доступно «Восстановить из корзины» (`Ctrl+Shift+Z`), в том числе после перезапуска.
- Безопасное перемещение требует IMAP MOVE или UIDPLUS. При отсутствии поддержки либо ошибке сервера письмо остаётся в локальном списке с сообщением об ошибке. Окончательное удаление из серверной корзины требует UIDPLUS и отдельного подтверждения; удаляются только выбранные UID.
- POP3 пока нет.

## Автоматическое получение почты

При запуске SimpleMail сразу проверяет включённые ящики. Если сервер поддерживает IMAP IDLE, программа держит отдельное фоновое соединение с INBOX и загружает новые письма по уведомлению сервера. После потери сети соединение восстанавливается автоматически; письма, пришедшие за время обрыва, проверяются при переподключении.

Проверка по таймеру остаётся резервным способом, а для серверов без IDLE — основным. Интервал задаётся в «Настройки → Автопроверка почты» (по умолчанию 10 минут). Значение 0 отключает только таймер: IDLE продолжает работать. Для получения уведомлений программа должна быть запущена.

## Язык интерфейса

В меню «Настройки → Язык интерфейса» доступны русский и **Srpski (latinica)**. Выбор сохраняется в настройках и применяется при следующем запуске SimpleMail. Перевод охватывает меню, окна настроек, редактор писем, уведомления и стандартные диалоги Qt. Содержимое писем, названия подписей и существующие папки хранения не переводятся.

## Порядок почтовых ящиков

Откройте «Настройки → Почтовые ящики». Перетащите ящик в списке либо выделите его и нажмите «Вверх» / «Вниз». Порядок сохраняется сразу, отображается в главном окне и остаётся после перезапуска. Новые ящики добавляются в конец списка.

В главном окне также можно нажать правой кнопкой мыши на название ящика и выбрать «Вверх» или «Вниз».

Это же меню позволяет проверить выбранный ящик, написать с него письмо, открыть «Настройки ящика…» и включить или отключить его проверку. В подменю «Настройки» доступны управление ящиками, подписи, спам-фильтр, интервал автопроверки и язык интерфейса.

## Значок и автозапуск Windows

У приложения собственная иконка окна и панели задач. Исходник: `mailclient/icons/simplemail.svg`; PNG и ICO для Windows пересобираются командой `python tools/build_app_icon.py`.

Включите «Настройки → Запускать при входе в Windows», чтобы SimpleMail запускался после входа в вашу учётную запись Windows. Эту же галочку можно снять для отключения автозапуска. Используется настройка только текущего пользователя; сохраняется путь к текущей базе писем, в том числе при запуске с `--data`. Пункт доступен также в подменю «Настройки» по правому клику на ящике.

## Готовое приложение Windows (EXE)

Запуск: `dist\SimpleMail\SimpleMail.exe`. Python на компьютере для запуска этой сборки не нужен. Сохраняйте всю папку `SimpleMail` вместе с подпапкой `_internal`; один EXE отдельно от неё не переносите. Существующая база писем и настройки используются из прежнего расположения `%APPDATA%\SimpleMail`.

Повторная сборка: закройте собранное приложение и запустите `powershell -File tools\build_windows.ps1`. Сборочные зависимости перечислены отдельно в `requirements-build.txt`; настройки упаковки находятся в `SimpleMail.spec`. В собранной версии автозапуск указывает на EXE и сохраняет текущий путь `--data`.
