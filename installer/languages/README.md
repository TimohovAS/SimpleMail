SerbianLatin.isl is the contributed Serbian Latin translation distributed by
Inno Setup, maintained by Davor Nikolić, based on Rancher's translation.
The original attribution header is preserved in the file.

Source: https://jrsoftware.org/files/istrans/
Upstream: https://github.com/jrsoftware/issrc/blob/main/Files/Languages/Unofficial/SerbianLatin.isl

Vendored so local builds and CI do not depend on an extra installed language file.
This version targets Inno Setup 6.5.0 or newer.
