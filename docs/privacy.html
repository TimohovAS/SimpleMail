Privacy Policy

Effective date: November 5, 2026

SimpleMail хранит почту на вашем компьютере и обращается напрямую к почтовому провайдеру. Разработчик не получает содержимое писем и токены доступа. Ниже описаны доступ, хранение и удаление данных.

Who provides SimpleMail

SimpleMail is an independent desktop email application maintained by TimohovAS. It is intended for personal use and a small group of users. There is no SimpleMail service that receives or stores your mailbox contents.

Google data accessed and why

  • Account identity: the openid and email permissions identify the Google account you authorize and help ensure it matches the mailbox configured in the application.
  • Email: the https://mail.google.com/ permission allows access to messages, headers, recipients, message bodies, attachments, mailbox folders and flags through Gmail IMAP and SMTP. SimpleMail uses this access to receive, display, search and send email, synchronize read and important flags, and move or delete messages as part of its email features. This broad permission, including the ability to permanently delete email, is required for Gmail IMAP/SMTP access.
  • OAuth tokens: access and refresh tokens let the application connect to Gmail and renew access without storing your Google password. Sign-in takes place in your browser on Google's own pages.

Local storage and security

Mailbox settings, message indexes, message text, drafts and outgoing messages are stored in a local SQLite database. Downloaded messages, including attachments, are stored as local EML files in the mailbox folders you select. Backups and files you export are written to destinations you choose. Mail databases, EML files and backups are not encrypted by SimpleMail; protect them with your computer's access controls and disk encryption where appropriate.

On Windows, OAuth tokens are stored locally under Windows DPAPI protection for the current user. If protected storage is unavailable, tokens remain only in memory and you must sign in again after restarting. OAuth tokens are excluded from SimpleMail backups. For accounts that use passwords instead of OAuth, the application uses the operating system credential store; if that store is unavailable, it displays a warning when using its database fallback.

Data use and sharing

SimpleMail communicates directly with your configured mail provider to perform email operations and with Google to obtain, refresh or revoke OAuth tokens. Sending email transmits the message to your mail provider and intended recipients. SimpleMail does not upload your mail, attachments or OAuth tokens to the developer.

Google user data is not sold, used for advertising, shared with data brokers or used to develop, improve or train generalized artificial intelligence or machine learning models. The developer does not routinely access your Google user data. Local spam classification uses data on your own computer.

SimpleMail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Other network connections

Checking for application updates contacts GitHub. Loading external images in an email contacts the servers hosting those images when you allow it, including for senders you have chosen to trust. Opening a link in an email uses your browser. Those services apply their own privacy policies. The desktop application does not include a separate advertising or analytics service.

This website is hosted by GitHub Pages. It does not use application analytics, advertising scripts or tracking cookies. GitHub may process request and technical logs as part of hosting; see the GitHub Privacy Statement.

Retention, revocation and deletion

Downloaded mail remains on your computer until you delete it. Removing an account from SimpleMail removes its database records and saved credentials. Downloaded EML files are kept by default; select the explicit file deletion option to remove tracked, unshared EML files inside that mailbox's storage folder. Manually exported files, backups and other copies you create must be removed separately. Uninstalling SimpleMail preserves local mail and settings.

You can sign out in the mailbox settings or revoke SimpleMail's access in your Google Account third-party connections. Revoking access prevents subsequent authorized access; it does not erase mail already downloaded to your computer or messages held by your provider and recipients.

Questions and changes

For questions about SimpleMail or this policy, use the project support page. Issues are public: do not include passwords, tokens, private messages or attachments. Changes to this policy will be published on this page with an updated effective date.
